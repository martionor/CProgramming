# Basic C Programming:

This is a simple C programming project repository that demonstrates the basics of the C language, such as variables, operators, control flow, functions, and more.

## 📘Project Description

This project aims to showcase the fundamental concepts of C programming, such as:
- Variable declaration and initialization
- Operators (arithmetic, logical, etc.)
- Conditional statements (if, else, etc.)
- Loops (for, while, etc.)
- Functions and function calls
- Basic input/output with scanf and printf
- Working with pointers (in some files)
- Simulating basic OOP concepts using struct

⚙️ Compilation & Execution

It’s ideal for beginners who are starting with C programming.


To compile any .c file into an executable (.exe) using gcc, use:

gcc -o <executable_name> <source_file.c>
example: gcc -o c_switch c_switch.c

run with:
./<file_name>
example:
./c_switch


💡 Tip
Make sure you have GCC installed. If not, you can install it through MinGW or your package manager.
